# 数据说明（DATA）

## 本仓库包含什么

仅 `data/processed/shenshu_42m_v1_sample/` 下的 1000 条样例（含完整中文命书，供文档 / 测试使用）。
**不包含**：条文库原文、全量训练数据、数据生成脚本。

## 全量数据如何产生（仓库外）

1. 自备合法的约 12000 条条文库 LUT（条文数 1001–13000 → 吉凶断词）。
2. 从六十甲子中均匀采样 年 / 月 / 日 / 时 四柱，并采样性别与六亲。
3. 用十九法规则：太玄数 → 年月起先天卦 → 互卦 → 基本数 → 八刻（+1327 回绕）→ 六亲定真刻 → 六门条号（见 README 1.4 节）。
4. 存为紧凑结构化 `.npy`（每行 27 字节），文本只在评测时由条号查表还原。
5. 划分：`blake2b(年柱索引:月柱索引) % 10000 < 118` → 验证集；同一年月柱不会同时出现在训练与验证集。

规模：训练 42,000,000 行，验证 500,000 行。

## 紧凑 Schema（`.npy` 结构化 dtype）

| 字段 | 类型 | 取值 |
|---|---|---|
| `sex` | u1 | 1=男，2=女，0=pad |
| `year_gan` … `hour_zhi` | u1 | 天干 1..10（甲=1），地支 1..12（子=1），0=pad |
| `father_zodiac` / `mother_zodiac` / `spouse_zodiac` | u1 | 1..12（鼠=1），0=pad |
| `brothers` / `sons` / `daughters` | u1 | 人数 |
| `verse_ids` | u2 × 6 | 六门 class id 0..11999（= 条文数 − 1001） |

## 样例 JSONL（`sample.jsonl`）

每行一个对象，包含 `sex`、`pillars`、`qin`、`target_text`（六门命书）与 `meta`（卦、基本数、八刻号、真刻、条号）。

## 已知限制

- 四柱为六十甲子均匀采样，**未与真实历法逐日对齐**。
